# Image Scraper

A Python script (Google Colab) that collects images by keyword from
search engines, so you don't have to download them one by one.

## What it does
- Enter any keyword, from general ("dog") to niche
- Choose how many images you want (the count is a target, not guaranteed)
- Pulls images using three scrapers: Google, Bing, and Baidu
- Typical run: about 2-3 minutes, versus 30-60 minutes by hand

## How to use
1. Open the notebook in Colab (use the badge at the top)
2. Set your keyword and image count
3. Run all cells

## Built with
Python, Google Colab
